# SCORVÉ – Luxury Fashion Website

SCORVÉ is a responsive fashion website designed to showcase luxury clothing, bags, jewellery, and perfumes.

## Features
- Responsive navigation bar
- Fashion collections
- Most Wanted section
- Product listing page
- Contact page
- Luxury-inspired design

## Technologies Used
- HTML
- CSS
- JavaScript

## Project
This project was created to practise front-end web development and build a stylish fashion shopping experience.
